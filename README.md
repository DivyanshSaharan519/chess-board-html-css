# ♟️ Chess Board using HTML & CSS

A simple Chess Board created using pure HTML and CSS.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- 8×8 chess board
- Chess pieces using Unicode characters
- Responsive board sizing
- CSS Grid layout
- Hover effect on chess squares

## 📸 Preview

The project displays a classic 8×8 chess board with black and white pieces.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
